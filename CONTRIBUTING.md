# Contribuindo

Obrigado por contribuir com a Jornada Git & GitHub! 🚀

## Fluxo de trabalho

1. Crie uma branch a partir de `develop`.
2. Use nomes descritivos, como `feature/nova-aula`, `fix/link-quebrado` ou `docs/melhorar-readme`.
3. Faça commits pequenos e objetivos seguindo Conventional Commits.
4. Abra um Pull Request para `develop`.
5. Descreva o que mudou, por que mudou e como validar.

## Commits

Exemplos:

```text
feat: adicionar desafio de rebase
fix: corrigir link da documentação
refactor: reorganizar exemplos de comandos
docs: atualizar guia de branches
chore: ajustar configuração do projeto
```

## Qualidade

- Prefira exemplos reproduzíveis.
- Evite comandos destrutivos sem aviso.
- Mantenha a documentação em português simples e direto.
- Atualize o índice quando criar novos capítulos.
