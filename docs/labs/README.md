# 🧪 Laboratórios

Os laboratórios são exercícios independentes para transformar a teoria em prática.

| Laboratório | Tema | Dificuldade |
|---|---|---|
| 01 | Fluxo básico | ⭐ |
| 02 | Branches | ⭐⭐ |
| 03 | Conflitos | ⭐⭐⭐ |
| 04 | Rebase | ⭐⭐⭐⭐ |
| 05 | Pull Request | ⭐⭐⭐ |

## Como usar

1. Leia o cenário.
2. Crie uma branch para o exercício.
3. Execute os comandos localmente.
4. Registre os resultados.
5. Abra um Pull Request quando o exercício pedir.

A ideia é que os laboratórios possam ser repetidos várias vezes até que o fluxo se torne natural.
