# Laboratório 01 — Fluxo básico

## Objetivo

Praticar o ciclo completo de alteração, staging e commit.

## Desafio

Crie um arquivo `meu-progresso.md`, escreva três aprendizados e registre a alteração em um commit.

## Comandos esperados

```bash
git status
git add meu-progresso.md
git diff --staged
git commit -m "docs: registrar progresso inicial"
git log --oneline -5
```

## Critérios de conclusão

- [ ] Arquivo criado
- [ ] Mudança staged
- [ ] Commit criado
- [ ] Histórico conferido
