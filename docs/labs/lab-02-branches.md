# Laboratório 02 — Branches

## Cenário

Você recebeu uma nova funcionalidade e precisa trabalhar sem alterar `main` diretamente.

## Desafio

Crie uma branch `feature/lab-branches`, faça uma alteração documental, registre um commit e prepare um Pull Request para `develop`.

## Checklist

- [ ] Branch criada a partir de `develop`
- [ ] Nome seguindo padrão
- [ ] Commit pequeno e descritivo
- [ ] Pull Request direcionado para `develop`
- [ ] Descrição do PR preenchida

## Extra

Repita o exercício criando uma branch `fix/corrigir-documentacao` e simule uma correção.
