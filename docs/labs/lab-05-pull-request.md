# Laboratório 05 — Pull Request profissional

## Objetivo

Simular uma entrega de equipe com descrição, checklist e revisão.

## Cenário

Uma nova aula foi criada em uma branch de feature. Você precisa entregar a mudança em `develop`.

## Checklist

- [ ] Título objetivo
- [ ] Contexto explicado
- [ ] Mudanças listadas
- [ ] Evidências incluídas quando necessário
- [ ] Testes ou validações descritos
- [ ] Branch atualizada
- [ ] Revisão solicitada

## Exercício extra

Faça uma revisão procurando links quebrados, comandos perigosos sem aviso e conteúdo duplicado.
